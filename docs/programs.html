The programs

Every program that comes with pIRCIS, in the folders PROG shows them in. Copy one and paste it in: Ctrl/Cmd-V on the emulator, PASTE FROM THE CLIPBOARD under PROG > New program on the phone. A runner starts at the top left, heading east, unless the program says otherwise.

Written one of your own? Send it in through GitHub, with a name and a line about what it does, and it can go on this page under Contributed.

Decoding

Base 64 source

run
>'7.'64.'*.'4.'+.'64.'*.'0.'+.'64.'*.'3.'+.'64.'*.'18.'+.&N.%" = "###@N.#$v
v.........................................................................<
>'HEADS.&N.%" = "###@N.#!..................................................
...........................................................................
..one number, reached two ways, printed twice each way.....................
...........................................................................
..row 0 does it by hand. HEADS in base64 is the digits 7 4 0 3 18,.........
..and row 0 multiplies by 64 and adds the next digit, five times over......
..no base64 anywhere in it, just arithmetic................................
...........................................................................
..row 2 writes 'HEADS. and lets the language read it. same number..........
...........................................................................
..% prints a number as base64 and # prints the same number in base 10,.....
..which is why each line shows it both ways................................
